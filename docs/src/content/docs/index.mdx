## Three commands

<CardGrid>
  <Card title="/slashforge:setup" icon="setting">
    One-time repo setup. Explores the codebase, asks clarifying questions, then
    generates `CLAUDE.md`, rules, skills, agents, commands, and hooks tailored
    to it.
  </Card>
  <Card title="/slashforge:code" icon="rocket">
    End-to-end development. Ten phases from plan to merged PR, with mandatory
    stop-and-confirm gates. Add `-quick` for lean mode on small changes.
  </Card>
  <Card title="/slashforge:investigate" icon="magnifier">
    Read-only research. Reproduces and root-causes a bug, then writes a findings
    report. Never touches your code.
  </Card>
</CardGrid>
