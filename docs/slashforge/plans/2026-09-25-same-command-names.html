Plan — The same command names on every host (5.0.0)

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans (the owner chose native execution) to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax.

Goal: Claude Code's commands become /slashforge-name, matching Cursor. Codex keeps $slashforge-name.

Architecture: - The templates are rewritten once into the form users type (/slashforge-name, and slashforge-name for bare skill names). - Claude installs flat command files (commands/slashforge-<name>.md) instead of the commands/slashforge/ folder, and an upgrade removes the 4.x files by exact name. - Only the Codex render changes the text, swapping a leading / for $. - The docs switcher follows the same rule.

Tech Stack: Node.js with no dependencies (CI runs Node 16 to 22), the node --test runner, and Astro for the docs site.

Spec: docs/slashforge/specs/2026-09-25-single-install-all-hosts-design.html, in the section "Addendum (2026-09-25): the same command names on every host — 5.0.0".

Global Constraints

  • Branch: work on feat/cursor-codex-targets (PR #58). Never merge it. No version bump here: 5.0.0 comes in a separate release PR.
  • Claude command files are ~/.claude/commands/slashforge-<name>.md (13 files). Not skills.
  • Only /slashforge: and bare slashforge: before a command name are renamed. Never commands/slashforge/, setup/slashforge/ or docs/slashforge/: those are paths, not command names.
  • The Codex swap only touches /slashforge- that is not inside a path (not preceded by a word character, ., /, ~ or -).
  • Upgrades: they remove only the 13 kit files in commands/slashforge/, plus the folder if it's empty. User files stay.
  • Commits end with Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>.

const fs = require("fs"), path = require("path");
// Command names only: never a path segment (preceded by a word char, . / ~ or -).
const RE = /(?<![\w.~-])(\/?)slashforge:([a-z][a-z-]*)/g;
let files = 0, hits = 0;
(function walk(d) {
  for (const e of fs.readdirSync(d, { withFileTypes: true })) {
    const p = path.join(d, e.name);
    if (e.isDirectory()) { walk(p); continue; }
    const s = fs.readFileSync(p, "utf8");
    const t = s.replace(RE, (m, slash, name) => { hits++; return `${slash}slashforge-${name}`; });
    if (t !== s) { fs.writeFileSync(p, t); files++; }
  }
})("templates");

  fs.writeFileSync(path.join(ns, 'mine.md'), 'mine');
  const out = execFileSync('node', [BIN, '--yes'], { env, encoding: 'utf8' });
  assert.deepEqual(fs.readdirSync(ns), ['mine.md']);
  assert.match(out, /4\.x commands/);
  // And with no user file, the folder goes too.
  fs.rmSync(path.join(ns, 'mine.md'));
  for (const c of COMMAND_FILES) fs.writeFileSync(path.join(ns, path.basename(c)), 'old');
  execFileSync('node', [BIN, '--yes'], { env });
  assert.ok(!fs.existsSync(ns));
});
