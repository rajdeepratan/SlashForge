Plan — Cursor and Codex targets

Goal: npx slashforge --target cursor installs the three workflow commands and nine discipline skills into .agents/skills/<name>/SKILL.md, discoverable by Cursor and Codex, with the Claude Code install byte-identical to today.

Architecture

A TARGETS descriptor table drives resolveTarget(), which gains a target parameter alongside the existing project flag. installFiles() branches on target.layout: the existing commands layout writes flat files to .claude/commands/slashforge/, while a new skills layout writes a directory per command and rewrites the frontmatter name to satisfy the Agent Skills contract.

No template file changes. {{INSTALL_PATH}} already carries guide cross-references at render time, so repointing it at ~/.agents/setup/slashforge/ keeps every reference valid.

Tech stack

Node.js >= 16, standard library only (fs, path, os, readline). Tests use the built-in runner: node --test, node:assert. No new dependencies.

Global constraints

  • Claude Code's installed output must be byte-identical to today. Every existing assertion in test/install.test.js stays green, unmodified.
  • No new runtime dependencies — Node standard library only.
  • No changes to any file under templates/.
  • .agents/skills/ is shared with other tools. Never remove a directory this installer did not write.
  • Default target is claude when --target is absent.
  • Commit after each task. Do not push to main.

    // Install targets. `claude` writes flat command files to .claude/commands/slashforge/,
// which is what produces the /slashforge:name form. `agents` writes the Agent Skills
// layout to .agents/skills/, read by both Cursor and Codex; that layout has no
// namespace, so the prefix is carried in the directory name instead.
const TARGETS = {
  claude: { dirname: '.claude', commandsSubdir: 'commands', layout: 'commands', namePrefix: '', omit: [] },
  agents: {
    dirname: '.agents',
    commandsSubdir: 'skills',
    layout: 'skills',
    namePrefix: 'slashforge-',
    // setup provisions .claude/agents, hooks and CLAUDE.md, none of which exist here.
    omit: [path.join('slashforge', 'setup.md')],
  },
};

// Users type the vendor they use, not the directory convention it shares.
const TARGET_ALIASES = { cursor: 'agents', codex: 'agents' };

function resolveTargetName(name) {
  const key = String(name == null ? 'claude' : name).trim().toLowerCase();
  const resolved = TARGET_ALIASES[key] || key;
  if (!TARGETS[resolved]) {
    throw new Error(`Unknown target '${name}'. Use one of: claude, cursor, codex, agents.`);
  }
  return resolved;
}

    // 'slashforge/code.md' -> 'slashforge-code'
function skillDirName(file, prefix = '') {
  return prefix + path.basename(file, '.md');
}

// Cursor and Codex require `name` to be lowercase letters, digits and hyphens only
// and to match the parent directory. Templates carry Claude Code's '/slashforge:code'
// form, so rewrite that one line. Bounded to the frontmatter block so a body line
// starting with 'name:' is never touched.
function toSkillFrontmatter(content, skillName) {
  const lines = content.split(/\r?\n/);
  const end = lines.indexOf('---', 1);
  for (let i = 1; i < end; i += 1) {
    if (/^name\s*:/.test(lines[i])) {
      lines[i] = `name: ${skillName}`;
      break;
    }
  }
  return lines.join('\n');
}

    function parseTargetArg(args) {
  const i = args.indexOf('--target');
  if (i !== -1 && args[i + 1]) return args[i + 1];
  const inline = args.find((a) => a.startsWith('--target='));
  return inline ? inline.slice('--target='.length) : 'claude';
}
