Plan — Per-agent docs content and layout fixes

Goal: Add a per-agent content directive to the docs, rewrite the six pages that compare all three agents side by side so each reader sees only their own, fix the four layout bugs the comparison caused, and add a build check that stops the over-wide tables coming back.

Architecture

A new remark-agent-only.mjs plugin turns a :::agent[claude] container directive into a <div class="agent-only" data-agent="claude"> block; CSS shows only the block whose data-agent contains the active data-target, which is already set before first paint. The wide 5-column per-agent tables are split into one narrow table per agent inside these blocks. The CLI reference and Migrating pages stay comparative on purpose and are left alone. A static post-build check (node:fs over dist/, no browser) backs the split up.

Tech stack

Astro 7 docs site. Markdown content with remark/rehype plugins (unist-util-visit, remark-directive already present). Plain CSS in one stylesheet. Tests are Node's built-in node --test at the repo root; CI also runs .github/scripts/check-docs-*.mjs over the built dist/.

Global constraints

  • Zero runtime/test dependencies at the repo root — the test suite is pure node --test; the width check must stay node:fs + regex, no browser.
  • Docs devDeps may not gain a headless browser. Reuse remark-directive / unist-util-visit, already present.
  • The built HTML must be correct for a reader with JavaScript off: it ships the Claude Code form, so Claude Code content is the no-JS default.
  • No user-facing doc may name a command in the colon form (/slashforge:code) except migrating.md and changelog.md; every command in prose is the /slashforge-<name> form, which the existing rehype plugin swaps per agent.
  • CSS media-query syntax stays classic (the build pins cssTarget for old Safari) — write (max-width: 640px), never range syntax.
  • Verified feature facts (do not restate the report's wrong guess): plan mode exists on all three agents (Claude Code & Cursor via Shift+Tab; Codex via /plan or Shift+Tab, v0.93.0, behind experimental collaboration_modes); a built-in /init exists on Claude Code (CLAUDE.md) and Codex (AGENTS.md) but not Cursor.

    import { visit } from 'unist-util-visit';
import { TARGETS } from '../targets.mjs';

const VALID = new Set(TARGETS);

/**
 * `:::agent[claude]` / `:::agent[claude,codex]` -> a block shown only when
 * that agent is the selected target. Visibility is pure CSS on data-agent
 * (see site.css); the built HTML defaults to Claude Code, so a no-JS reader
 * still sees the Claude content.
 */
export function remarkAgentOnly() {
  return (tree, file) => {
    visit(tree, (node) => {
      if (node.type !== 'containerDirective' || node.name !== 'agent') return;

      // remark-directive parses `[claude,codex]` into a leading paragraph
      // flagged directiveLabel. Pull it out so it is not rendered as body.
      let raw = '';
      const first = node.children[0];
      if (first?.data?.directiveLabel && first.children?.length) {
        raw = first.children.map((c) => c.value ?? '').join('');
        node.children.shift();
      }

      const agents = raw.split(',').map((s) => s.trim()).filter(Boolean);
      const valid = agents.filter((a) => VALID.has(a));
      const unknown = agents.filter((a) => !VALID.has(a));
      if (!agents.length) file.message('":::agent" needs a target, e.g. :::agent[claude].', node);
      if (unknown.length) file.message(`":::agent" unknown target(s): ${unknown.join(', ')}.`, node);

      node.data = {
        ...node.data,
        hName: 'div',
        hProperties: { class: 'agent-only', 'data-agent': valid.join(' ') },
      };
    });
  };
}

    import { readFileSync, readdirSync, statSync } from 'node:fs';
import { join } from 'node:path';

const AGENTS = ['Claude Code', 'Cursor', 'Codex'];
const MAX_COLS = 4;
const COMPARE_OK = ['/reference/cli/', '/reference/migrating/'];

export function widthProblems(html, { allowCompare }) {
  const out = [];
  for (const m of html.matchAll(/<table[\s\S]*?<\/table>/g)) {
    const table = m[0];
    const firstRow = (table.match(/<tr[\s\S]*?<\/tr>/) || [''])[0];
    const cols = (firstRow.match(/<t[hd][\s>]/g) || []).length;
    if (cols > MAX_COLS) out.push(`table has ${cols} columns (max ${MAX_COLS}); split it per agent`);
    if (!allowCompare) {
      const headText = firstRow.replace(/<[^>]+>/g, ' ');
      const named = AGENTS.filter((a) => headText.includes(a));
      if (named.length >= 2)
        out.push(`table header compares ${named.join(', ')}; use :::agent blocks or move it to the CLI reference`);
    }
  }
  return out;
}

// CLI: walk dist/ and report. Skipped when imported (import.meta.main-style guard).
const invokedDirectly = process.argv[1] && process.argv[1].endsWith('check-docs-width.mjs');
if (invokedDirectly) {
  const base = process.env.DOCS_BASE_PATH ?? '/slashforge';
  const root = join(process.cwd(), 'dist' + base);
  const pages = [];
  (function walk(dir) {
    for (const e of readdirSync(dir)) {
      const p = join(dir, e);
      if (statSync(p).isDirectory()) walk(p);
      else if (e === 'index.html') pages.push(p);
    }
  })(root);

  let bad = 0;
  for (const page of pages) {
    const rel = page.slice(root.length);
    const allowCompare = COMPARE_OK.some((s) => rel.includes(s));
    for (const msg of widthProblems(readFileSync(page, 'utf8'), { allowCompare })) {
      console.error(`  ✗ ${rel}: ${msg}`);
      bad++;
    }
  }
  if (bad) { console.error(`\n${bad} width problem(s).`); process.exit(1); }
  console.log('✓ no over-wide or unnecessary per-agent table');
}
