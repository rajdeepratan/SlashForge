Plan — derive the published version from package.json

Goal: Replace both hardcoded version literals with a single derived source, and guard the build against either being written by hand again.

Architecture

Three tasks. The guard goes first and is proven to fail against the current build — 17 findings, a measured number, not an estimate. The shared module then turns it green. The CI matrix change comes last because its outcome is genuinely unknown and must not block the fix.

Tech stack

Node built-ins only — node:fs, node:path, ESM. Astro frontmatter and src/*.ts modules run in Node at build time, so the manifest can be read without entering Vite's module graph.

Global constraints

  • Zero dependencies.
  • Do not modify docs/package-lock.json. A macOS-regenerated lockfile omits Linux optional dependencies and breaks CI's npm ci. If node_modules is missing, restore with npm ci. Prefer npm run over npx astro, which has rewritten the lockfile before.
  • Derive once, consume twice. Reading the manifest separately in each file would repeat, in the fix, the duplication that caused the bug.
  • The existing suite (43 tests), the docs build, the link check and the accessible-name guard must all stay green.

Task 1: Write the guard and prove it catches both literals

Files: Create .github/scripts/check-docs-facts.mjs

Interfaces

  • Consumes: the built docs/dist/ tree and ../package.json. Run from docs/.
  • Produces: an executable wired into CI in Task 3.
  • ☐ Step 1: Build
    Run: cd docs && npm run build
  • ☐ Step 2: Write the guard 
    #!/usr/bin/env node
/**
 * Fails if a published version string in the built docs disagrees with package.json.
 *
 * The site restated its version by hand in two places — the hero and the shared
 * footer — and both froze at v4.0.1 while npm served 4.3.1. Seventeen stale
 * strings across sixteen pages, live. The values are derived now, so this should
 * always pass; its job is to fail if anyone writes one by hand again.
 *
 * Run from docs/ after `npm run build`.
 */
import { readFileSync, existsSync, readdirSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';

const DIST = 'dist';

if (!existsSync(DIST)) {
  console.error(`::error::${DIST}/ not found — run the build first`);
  process.exit(1);
}

const pkg = JSON.parse(readFileSync(join('..', 'package.json'), 'utf8'));
const expected = `v${pkg.version}`;

const pages = [];
(function walk(dir) {
  for (const entry of readdirSync(dir)) {
    const p = join(dir, entry);
    if (statSync(p).isDirectory()) walk(p);
    else if (p.endsWith('.html')) pages.push(p);
  }
})(DIST);

// Deliberately narrow: only a bare vN.N.N alone inside a <span>. The changelog
// page legitimately lists every past release, and a looser pattern would flag
// all of them.
const CHIP = /<span>(v\d+\.\d+\.\d+)<\/span>/g;

let wrong = 0;
for (const page of pages) {
  const html = readFileSync(page, 'utf8');
  for (const [, found] of html.matchAll(CHIP)) {
    if (found === expected) continue;
    console.error(
      `::error file=docs/${relative('.', page)}::shows ${found}, package.json says ${expected}`
    );
    wrong++;
  }
}

console.log(`checked ${pages.length} pages against ${expected}`);

if (wrong > 0) {
  console.error(`${wrong} stale version string(s)`);
  process.exit(1);
}

console.log('every published version string matches package.json');

    Run: cd docs && node ../.github/scripts/check-docs-facts.mjs
    Expected: exit 1. Sixteen from the shared footer, plus one extra on index.html for the hero chip. Seventeen is the measured number — it came from dry-running this guard before the plan was written. A different count means the pattern is wrong: fewer and it is missing a surface, more and it is catching the changelog's release list.

  • ☐ Step 1: Create the shared module

const pkg = JSON.parse(
  readFileSync(new URL('../../package.json', import.meta.url), 'utf8')
);

/** The published version, e.g. "4.3.1". */
export const version: string = pkg.version;

/** The engines floor as a display string: ">=16" -> "16+", ">=18.0.0" -> "18+". */
export const nodeFloor: string =
  `${pkg.engines.node.replace(/[^0-9.]/g, '').split('.')[0]}+`;

Verification of the whole change

The guard reports 17 before Task 2 and 0 after, and both numbers must be observed rather than assumed. To re-prove later: restore either literal, rebuild, run the guard, revert, rebuild, run again.

Out of scope

  • The quickstart block and a hero copy button — product decisions, their own change.
  • Raising engines, unless CI proves 16 unsupportable.
  • The MIT literals. A licence does not change with releases.
