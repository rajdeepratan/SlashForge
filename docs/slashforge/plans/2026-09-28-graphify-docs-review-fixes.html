  • ☑ Step 3: Implement. 
    function frontmatterEnd(lines) {
  const end = lines.findIndex((l, i) => i > 0 && l.trim() === '---');
  if (lines[0].trim() !== '---' || end === -1) throw new Error('frontmatter has no closing --- fence');
  return end;
}
    Use it in withPreamble and withFrontmatterLine. renderSkill reads commandFiles from its options (default COMMAND_FILES). installAgentsFiles passes { ...opts, commandFiles }.
